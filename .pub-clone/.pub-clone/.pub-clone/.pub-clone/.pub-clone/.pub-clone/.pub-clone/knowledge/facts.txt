jak zabezpieczyc haslo; silne haslo => Hasła przechowuje się jako skróty z solą i wieloma iteracjami, np. bcrypt lub Argon2, nigdy jawnym tekstem.

programowanie => Programowanie to proces tworzenia instrukcji, które komputer wykonuje.
kochac; zakochanie; zakochac sie; zakochac => Miłość to więź oparta na bliskości, trosce i zaangażowaniu; rośnie, gdy jest pielęgnowana codziennie, nie tylko od święta.
zdradzic; zdradzil mnie => Zdrada rani zaufanie u podstaw; odbudowa jest możliwa, ale wymaga pełnej szczerości, odpowiedzialności i czasu.
zwiazek => W zdrowym związku obie strony dbają o bliskość, szacunek i jasną komunikację; relacja wymaga uwagi na co dzień.
zaufanie => Zaufanie buduje się przez przewidywalność, szczerość i dotrzymywanie słowa; odbudowuje się długo i konsekwentnie.
szacunek => Szacunek to traktowanie drugiej osoby jako równej, bez wyśmiewania, upokarzania i kontroli.
komunikacja => Dobra komunikacja to mówienie wprost o uczuciach i potrzebach oraz słuchanie bez przerywania i oceniania.
gpio => GPIO to uniwersalne piny wejścia-wyjścia w Raspberry Pi i mikrokontrolerach; pozwalają podłączyć czujniki, przekaźniki i diody.
raspberry pi => Raspberry Pi to niewielki jednopłytkowy komputer, często używany do nauki, projektów i serwerów; model Pi 5 ma 4 rdzenie ARM i do 16 GB RAM.
ssh => SSH to bezpieczny, szyfrowany protokół zdalnego logowania i przesyłania plików; zastąpił nieszyfrowany telnet.
dns => DNS to „książka telefoniczna” internetu: zamienia nazwy domen, np. wp.pl, na adresy IP.
ip => Adres IP to unikalny numer urządzenia w sieci; IPv4 ma 32 bity, a nowszy IPv6 aż 128.
ssl => TLS, dawniej SSL, to protokół szyfrujący połączenia internetowe; certyfikat potwierdza tożsamość serwera.
vpn => VPN tworzy szyfrowany tunel przez internet, dzięki któremu ruch wychodzi tak, jakby pochodził z innej sieci.
kontener => Kontener, np. Docker, pakuje aplikację z zależnościami i uruchamia ją izolowanie, dzieląc jądro z systemem gospodarza.
git => Git to rozproszony system kontroli wersji, który śledzi zmiany w plikach i pozwala pracować wielu osobom równocześnie.
cpu => Procesor, czyli CPU, to układ wykonujący instrukcje programu i sterujący pracą komputera.
ssd => SSD to dysk półprzewodnikowy bez ruchomych części, szybszy i bardziej odporny niż talerzowy HDD.
ram => RAM to pamięć operacyjna komputera, szybka i ulotna, przechowująca dane na czas pracy programów.
szczescie; bycie szczesliwym => O szczęściu decydują w dużej mierze bliskie relacje, zdrowie, poczucie sensu i wdzięczność, a nie same pieniądze.
